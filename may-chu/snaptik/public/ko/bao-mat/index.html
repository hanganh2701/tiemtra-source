요약

snaptik은 계정이 필요 없고, 추적 쿠키를 쓰지 않고, 광고나 방문자 분석 도구가 없으며, 내려받은 영상을 저장하지 않아요.

서버가 받는 정보

  • 붙여넣은 링크: 서버는 이 링크로 해당 TikTok 페이지를 열어 결과를 돌려줘요. 링크는 기록되지 않아요.
  • 게시물의 공개 정보(설명, 계정 이름, TikTok 서버의 파일 링크): 다음에 다운로드를 누를 때 TikTok을 다시 읽지 않도록 Cloudflare 캐시에 10분간 임시로 보관한 뒤 자동으로 삭제돼요.
  • IP 주소: 분당 검색 횟수를 제한하는 데 그 순간에만 쓰고, snaptik은 저장하지 않아요.
  • snaptik은 Cloudflare에서 운영돼요. Cloudflare는 서비스 운영과 공격 방어를 위해 자체 정책에 따라 기술 로그(접속 시간, IP)를 남길 수 있어요.

내 기기에 저장되는 것

  • 검색 기록(최근 게시물 최대 20개: 게시물 id, 계정 이름, 커버 이미지, 설명 일부)은 내 기기의 브라우저 저장소에 저장되고, 어디로도 보내지 않아요. 메인 페이지에서 기록 삭제를 누르면 지울 수 있어요.
  • snaptik을 홈 화면에 추가하면 브라우저가 더 빨리 열 수 있도록 페이지 사본을 보관해요.
  • 언어 선택 버튼으로 고른 언어도 브라우저에 저장돼서, 다음에 같은 언어로 열려요. 고르지 않았다면 기기 언어를 따라요.

TikTok의 이미지

커버 이미지, 프로필 사진, 미리보기 이미지는 브라우저가 TikTok 서버에서 직접 불러와요. snaptik은 이 이미지들을 불러올 때 페이지 주소(referrer)를 보내지 않도록 해 두었어요.
