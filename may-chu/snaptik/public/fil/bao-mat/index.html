Patakaran sa Privacy

Na-update noong Oktubre 16, 2026.

Sa madaling salita

Hindi kailangan ng account ang snaptik, hindi ito naglalagay ng tracking cookie, walang ads o tool na nagbibilang ng bisita, at hindi nito sine-save ang mga video na dina-download mo.

Ano ang natatanggap ng server

  • Ang link na ipinaste mo: ginagamit ng server ang link para buksan ang katumbas na page sa TikTok at ibalik sa iyo ang resulta. Hindi nire-record ang link.
  • Pampublikong impormasyon ng post (caption, username, link ng file sa server ng TikTok): pansamantalang itinatago nang 10 minuto sa cache ng Cloudflare para hindi na kailangang basahin ulit ang TikTok sa susunod mong pagpindot ng download, at saka kusang binubura.
  • IP address: ginagamit lang sa mismong sandaling iyon para limitahan ang dami ng paghahanap kada minuto; hindi ito sine-save ng snaptik.
  • Tumatakbo ang snaptik sa Cloudflare. Maaaring mag-record ang Cloudflare ng technical log (oras ng pag-access, IP) ayon sa sarili nilang patakaran para mapatakbo ang serbisyo at maprotektahan ito laban sa mga atake.

Sa device mo

  • Ang history ng paghahanap (hanggang 20 pinakahuling post: id ng post, username, cover, bahagi ng caption) ay naka-save sa storage ng browser sa device mo at hindi ipinapadala kahit saan. Pindutin ang I-clear ang history sa home page para burahin ito.
  • Kapag in-install mo ang snaptik sa home screen, nagtatabi ang browser ng kopya ng mga page para mas mabilis itong bumukas.
  • Ang wikang pinili mo gamit ang language button ay naka-save din sa browser, para tamang wika ang bumukas sa susunod. Kung wala ka pang pinili, susundin ng site ang wika ng device mo.

Mga larawan mula sa TikTok

Ang cover, profile picture at mga preview image ay direktang dina-download ng browser mo mula sa server ng TikTok. Pinapatay ng snaptik ang pagpapadala ng address ng page (referrer) kapag dina-download ang mga larawang ito.
