Cara Download Video TikTok

Semua cara dimulai dari link postingannya. Di aplikasi TikTok: buka video atau postingan foto, ketuk tombol Bagikan (panah melengkung) lalu pilih Salin tautan. Di komputer: buka video di tiktok.com lalu salin alamat di bilah alamat browser.

Di HP Android

  1. Salin link video di aplikasi TikTok.
  2. Buka snaptik.meomeo.app di Chrome, ketuk Tempel. Saat pertama kali, Chrome mungkin meminta izin membaca papan klip, pilih Izinkan.
  3. Ketuk Unduh video tanpa watermark (atau versi HD, musik MP3).
  4. File ada di folder Download; aplikasi Galeri atau Google Foto akan menampilkan videonya setelah beberapa detik.

Di iPhone, iPad

  1. Salin link video di aplikasi TikTok.
  2. Buka snaptik.meomeo.app di Safari, ketuk Tempel lalu pilih Izinkan Tempel.
  3. Ketuk tombol unduh; saat Safari bertanya, pilih Unduh. Ikon panah biru di bilah alamat menunjukkan progresnya.
  4. Buka aplikasi File › Unduhan, ketuk videonya, lalu ketuk Bagikan › Simpan Video untuk memasukkannya ke aplikasi Foto.

Perlu iOS 13 atau lebih baru. Browser lain di iPhone (Chrome, Firefox) juga bisa mengunduh, dan filenya tetap masuk ke aplikasi File.

Di komputer

  1. Buka video di tiktok.com, salin alamat di bilah alamat browser (Ctrl+L lalu Ctrl+C, di Mac pakai ⌘).
  2. Buka snaptik.meomeo.app, tempel ke kolom (Ctrl+V) lalu klik Unduh.
  3. Pilih versi yang ingin diunduh. File masuk ke folder Unduhan (Downloads).

Pasang snaptik di layar utama

snaptik bisa dipasang seperti aplikasi kecil, tanpa lewat toko aplikasi, dan hampir tidak memakan ruang penyimpanan.

  • Android (Chrome): ketuk tombol Instal aplikasi di bagian atas halaman, atau menu ⋮ › Tambahkan ke layar utama.
  • iPhone, iPad (Safari): ketuk tombol Bagikan › Tambah ke Layar Utama.
  • Komputer (Chrome, Edge): klik ikon instal di ujung bilah alamat.

Unduh langsung dari tombol Bagikan (Android)

Setelah snaptik dipasang lewat Chrome di Android, snaptik muncul di daftar berbagi HP kamu. Di TikTok, ketuk Bagikan › Lainnya (atau ikon tiga titik) › snaptik: situs terbuka dan langsung mencari videonya, tanpa perlu salin-tempel.

Unduh langsung dari tombol Bagikan (iPhone, iPad)

iPhone tidak mengizinkan situs web masuk ke tombol Bagikan seperti di Android, tapi aplikasi Pintasan bawaan iPhone bisa melakukannya. Cukup buat sekali:

  1. Buka aplikasi Pintasan (Shortcuts), ketuk + untuk membuat pintasan baru, lalu beri nama “Unduh dengan snaptik”.
  2. Buka pengaturan pintasan (ikon ⓘ), aktifkan Tampilkan di Lembar Bagikan (Show in Share Sheet). Di bagian jenis input yang diterima, pilih hanya URL dan Teks.
  3. Tambahkan tindakan Enkode URL (URL Encode) dengan input Input Pintasan (Shortcut Input).
  4. Tambahkan tindakan URL, ketik https://snaptik.meomeo.app/id/?url= lalu sisipkan variabel URL Terenkode (URL Encoded Text) tepat setelah tanda =.
  5. Tambahkan tindakan Buka URL (Open URLs), lalu ketuk Selesai.

Setelah itu, di TikTok ketuk Bagikan › Lainnya (ikon tiga titik) › Unduh dengan snaptik: Safari membuka snaptik dan langsung mencari videonya, tanpa perlu salin-tempel.

Nama menu bisa sedikit berbeda tergantung versi iOS dan bahasa perangkat.

Bookmarklet untuk komputer

Seret tombol di bawah ini ke bilah bookmark browser. Saat sedang menonton video di tiktok.com, klik bookmark itu dan snaptik akan terbuka dengan video tersebut.

Unduh dengan snaptik

Tombol ini untuk diseret ke bilah bookmark (tekan Ctrl+Shift+B untuk menampilkan bilah bookmark), bukan untuk diklik di sini.

Kalau tidak bisa diunduh

  • Buka lagi link-nya di TikTok, cek apakah postingannya masih ada atau diatur privat.
  • Link harus berupa link postingan (berisi /video/, /photo/, atau link pendek vt.tiktok.com), bukan link profil.
  • TikTok kadang memblokir server untuk sementara: tunggu beberapa menit lalu coba lagi.
  • Tombol unduh tidak merespons di iPhone: cek Pengaturan › Safari › Unduhan, dan pastikan ruang penyimpanan masih cukup.
