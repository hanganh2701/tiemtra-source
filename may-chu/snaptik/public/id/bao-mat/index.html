Kebijakan Privasi

Diperbarui pada 16 Oktober 2026.

Singkatnya

snaptik tidak perlu akun, tidak memasang cookie pelacak, tidak memakai iklan atau alat penghitung pengunjung, dan tidak menyimpan video yang kamu unduh.

Apa yang diterima server

  • Link yang kamu tempel: server memakai link itu untuk membuka halaman TikTok yang sesuai lalu mengembalikan hasilnya kepadamu. Link tidak dicatat.
  • Informasi publik postingan (deskripsi, nama akun, link file di server TikTok): disimpan sementara selama 10 menit di cache Cloudflare agar saat kamu menekan unduh berikutnya tidak perlu membaca TikTok lagi, lalu terhapus otomatis.
  • Alamat IP: hanya dipakai sesaat untuk membatasi jumlah pencarian per menit, snaptik tidak menyimpannya.
  • snaptik berjalan di Cloudflare. Cloudflare mungkin mencatat log teknis (waktu akses, IP) sesuai kebijakan mereka sendiri untuk operasional dan mencegah serangan.

Di perangkatmu

  • Riwayat pencarian (maksimal 20 postingan terakhir: id postingan, nama akun, gambar sampul, cuplikan deskripsi) disimpan di penyimpanan browser di perangkatmu, tidak dikirim ke mana pun. Ketuk Hapus riwayat di beranda untuk menghapusnya.
  • Saat snaptik dipasang di layar utama, browser menyimpan salinan halaman agar bisa dibuka lebih cepat.
  • Bahasa yang kamu pilih lewat tombol pilihan bahasa juga disimpan di browser, agar lain kali terbuka dalam bahasa yang sama. Kalau belum memilih, situs mengikuti bahasa perangkat.

Gambar dari TikTok

Gambar sampul, foto profil, dan gambar pratinjau diunduh browser kamu langsung dari server TikTok. snaptik mematikan pengiriman alamat halaman (referrer) saat memuat gambar-gambar ini.
